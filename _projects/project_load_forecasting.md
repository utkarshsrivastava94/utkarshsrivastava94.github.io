### Overview

An end-to-end machine learning system for forecasting hourly electricity demand using real-world weather and load data from Kaggle.

### Key Achievements

- Trained a high-accuracy `RandomForestRegressor` model achieving **R² = 0.991** on time-series electricity load data.
- Engineered lag-based and time-based features (hour of day, day of week, rolling means) to significantly improve forecasting accuracy.
- Deployed the model as a **FastAPI** REST service with live inference endpoints using Uvicorn.
- Implemented structured logging and API usage monitoring for production observability.

### Tech Stack

`Python` · `Scikit-learn` · `FastAPI` · `Uvicorn` · `Pandas` · `Time Series Forecasting` · `REST APIs`
